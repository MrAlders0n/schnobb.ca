Security by day. Mesh radio after hours.

I'm Chris Schnobb, online as MrAlders0n. I've spent ten years in IT security, which mostly teaches you how much depends on the internet staying up.

That got me into radio, then LoRa, then building a mesh network around Ottawa that works without it. I also fly a drone when I travel.

eps1.0_projects.txt

Please enjoy each project equally.

  • MeshMapper

    Coverage maps for MeshCore networks, built from radio data the community collects with the MeshMapper app.

    meshmapper.net
  • MeshCore Beacon

    Watches a mesh from above: live packets, nodes, routes and traces on a map and in lists.

    github.com/MeshCore-Beacon
  • MeshCore Canada

    Community documentation and network tools for MeshCore across Canada, in English and French.

    meshcore.ca
  • Ottawa Mesh

    The off-grid LoRa mesh network around Ottawa, run by local radio enthusiasts.

    ottawamesh.ca
  • Everything else

    Firmware builds, repeater tooling and scripts.

    github.com/MrAlders0n
