About GitHub

Hi,

I'm Chris, known in the mesh community as MrAlders0n. Father, husband, and IT security consultant for the past ten years.

A side effect of working in security is that you quickly realize how fragile the internet is, whether from natural disaster or cyber attack. The world relies heavily on digital communications with no fallback.

A work engagement introduced me to RF, and that curiosity led me into LoRa and mesh networking. Most of my free time goes to my family. Whatever is left goes into building the Ottawa mesh and the tools around it.

Projects

  • MeshMapper Coverage maps for MeshCore networks, built from radio data the community collects with the MeshMapper app.
  • MeshCore Beacon Watches a mesh from above: live packets, nodes, routes and traces on a map and in lists.
  • MeshCore Canada Community documentation and network tools for MeshCore across Canada, in English and French.
  • Ottawa Mesh The off-grid LoRa mesh network around Ottawa, run by local radio enthusiasts.
  • Everything else Firmware builds, repeater tooling and scripts on GitHub.
